使用说明（保留）

1. 两种练法：对照跟打练准确率（照绿字打，打完自动结算）；自由练习练速度（看速度曲线是否平稳）。
2. 选中即复制：输入框和对照区拖选 / 双击 / Shift+方向键 / Ctrl+A 都会自动复制，输入框下方的开关可关。浏览器若拦剪贴板（file:// 或非 HTTPS）会提示你按 Ctrl+C。
3. 计时：第一次敲键自动开始。挑战时长选 1/3/5 分钟，时间到自动结算。
4. 编辑区是 VS Code 手感：Ctrl+Backspace 按词删、Ctrl+Enter / Shift+Enter 下方插行、Ctrl+D 连选、Alt+↑↓ 移行、Tab 缩进、Ctrl+Z 撤销。完整表见输入框下方「编辑快捷键」。复制全部请点按钮。
5. 看什么：中文看 字/分，英文看 词/分；退格率 >8% 说明太赶，先降速保 50 字不断删；节奏“飘”说明停顿多，同一篇短文连打 3 遍。
6. 提分套路：定目标（如 120字/分 + 95%）→ 打一段 → 看复盘和教练建议 → 用错题本强化 → 再打同一段，分数涨得最快。
7. 离线：本项目无 CDN，图表库在 vendor/chart.umd.min.js，文本在 texts/samples.json，双击 index.html 或 python3 -m http.server 后打开 http://localhost:8000/ 都可，推荐后者（剪贴板最稳）。
8. 隐私：内容、成绩、错题、击键统计只存本机 localStorage，不联网。
9. 主题与专注：右上主题按钮在 自动 / 浅色 / 深色 间切换，默认跟随系统；练习区右上「🧘 专注」只留练习区并放大，点「↩ 退出专注」回来查看评分。
